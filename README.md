# Dostaffkin — урок 5

Проект собран на основе предоставленного шаблона преподавателя `dostaffkin-main`.

В проекте настроены Angular-компоненты Header, Home, Order и Track, маршруты и публикация через GitHub Actions.

Важно: формы Order и Track пока являются учебными макетами; расчёт маршрута, отправка заказа и получение статуса не подключены. Это не копия ранее принятой самостоятельной работы.

Для GitHub Pages репозитория `dostaffkin` используется базовый путь `/dostaffkin/`.
